# Lua IPC channel implementation plan

> **For agentic workers:** implement task-by-task; each task ends with a
> runnable check. The spec is
> `docs/superpowers/specs/2026-09-03-lua-ipc-design.md` (normative).

**Goal:** `notmutt lua '<chunk>'` relays a Lua chunk over a same-user unix
socket to a live session; the session runs it on a fresh R8 sandbox VM and
returns print output / error to the caller.

**Architecture:** reuse `runLuaCommand`'s VM machinery (extracted as
`runLuaChunk`), the read-only `metadataCtxTable`, and the MCP/bus event
patterns. Client = unconditional; server = `//go:build lua`; peer check =
linux-only SO_PEERCRED with dir-perms fallback. No new dependencies.

**Tech Stack:** Go, gopher-lua (already in the lua build), stdlib
`net`/`os`/`encoding/json`, vendored `golang.org/x/sys/unix`.

**Docs:** this plan + the spec are committed first (Co-Authored-By:
Deepseek). Code commits carry no co-author.

The mailbox privacy rule applies: never run ./notmutt interactively; the
user does the interactive pass.

## Task 3: client + shared framing

**Files:** `src/app/lua_ipc.go` (no build tag)

- `luaSocketPath() string`: `RuntimeHome()` else `StateHome()`, join
  `notmutt`, return `<dir>/ipc.sock`.
- `ipcRequest{ThreadID, Chunk string}`, `ipcReply{Output, Err string}`,
  `const maxIPCChunk = 1 << 20`.
- `allowPeer(peer uint32) bool` = `peer == uint32(os.Getuid())`.
- `luaSend(sock string, req ipcRequest) (ipcReply, error)`: dial 2s, write
  JSON request, read reply with a 6m deadline, `json.Unmarshal`.
- `luaOnce(args []string) error`: flag `-t`; chunk = joined positional args
  else stdin; empty chunk errors; prints reply.Output to stdout, returns
  reply.Err.

**Check:** `go build ./app/` (and `-tags "lua mcp"`).

## Task 4: refactor runLuaCommand

**Files:** `src/app/lua_action.go` (lua tag)

Extract the load/call/drain body of `runLuaCommand` (lines 215-248) into

**Check:** existing `TestRunLuaCommand` + `TestLuaCommandPrompt` still pass.

## Task 5: IPC server + peer check

**Files:** `src/app/lua_ipc_server.go` (`//go:build lua`),
`src/app/lua_ipc_peer_linux.go` (`linux`), `src/app/lua_ipc_peer_other.go`
(`!linux`)

- `wireLuaIPC(ctx, bus, worker, cfg)` = `go serveLuaIPC(...)`, logging a
  listen error (never fatal - a second session skips).
- `serveLuaIPC` -> `serveLuaIPCat(ctx, ..., sock string)`: MkdirAll 0700;
  probe an existing socket (500ms dial) - live = "in use", else remove;
  `net.Listen("unix", sock)`; ctx goroutine closes + removes; accept loop.
- `handleIPCConn`: `peerCheck(conn)`; read under `io.LimitReader(
  maxIPCChunk+1)` with a 30s deadline; Unmarshal; `runLuaChunk(req.Chunk,
  req.ThreadID, ..., ipcCtx)` where `ipcCtx` merges `ctxTable(vm, false)`
  with `metadataCtxTable(vm, worker, nil, nil)` (ForEach, the ctxTable(net)
  pattern at lua_action.go:358); JSON reply; close.
- `peerCheck(conn net.Conn) error`: linux = SO_PEERCRED via
  `unix.GetsockoptUcred` + `allowPeer`; `!linux` = nil (dir perms).

**Check:** `go build -tags "lua mcp" ./app/`.
